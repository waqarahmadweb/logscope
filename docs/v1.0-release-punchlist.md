## §1 — Blockers (must fix before zip)

### 1.1 🔒 `log_path` = arbitrary file read + rename inside the WordPress root — 🔴 High-sev security · M

The allowlist is `ABSPATH` + `WP_CONTENT_DIR` (the whole install tree) and `log_path`
is sanitized only for null bytes/whitespace — no `*.log` leaf restriction. A holder of
`logscope_manage` (a discrete, grantable cap, **not** equivalent to `manage_options`) can:

1. `POST /settings` `{"log_path":"<ABSPATH>/wp-config.php"}` — accepted; `/settings/test-path` even confirms readable.
2. `GET /logs/download` → `readfile()` streams **wp-config.php** (DB creds, all salts). `GET /logs` parses & returns it too.
3. `DELETE /logs?confirm=true` → **renames** `wp-config.php` → `wp-config.php.cleared-<ts>` — takes the site down AND leaves creds served as **public plaintext** (non-`.php` extension) to unauthenticated visitors.

- Files: `src/Support/PathGuard.php:71-83`, `src/Settings/SettingsSchema.php:57-72`, `src/Log/FileLogSource.php:58-81`, `src/REST/LogsController.php:328` (download) / `:267-279` (clear rename), `src/REST/SettingsController.php:248` (test-path oracle).
- Fix: restrict the resolved leaf to a log pattern (`*.log` / `debug.log*`), refuse `download` + `clear` when the resolved path is not a log file, and additionally gate the destructive `DELETE /logs` on `current_user_can('manage_options')` rather than the plugin cap. `test-path` should apply the same leaf restriction so it stops being an existence/readability oracle for arbitrary files.
- [x] Done — `PathGuard::is_log_basename()` enforced in `FileLogSource` (constructor throw), `SettingsController` (400 on save + test-path), `SettingsSchema` (sanitizer backstop), and `LogsController` (download/clear refusals); clear also gated on `manage_options`. Tests added.

### 2.2 Retention feature has no UI — unreachable from the shipped app — 🟠 · M

Server side fully wired (`SettingsSchema` keys `retention_enabled`/`retention_max_size_mb`/`retention_max_archives`, `POST /settings` accepts them, `CronScheduler` schedules `logscope_rotate_logs`, `uninstall` cleans them) but **no Settings-panel field exists** and `handleSave` never sends the keys. - Files: `assets/src/components/SettingsPanel/index.jsx:166`, `readme.txt:29`.
- [x] Done — added the Settings UI (toggle + max-size + archives fields in the Log file section, validated, wired into dirty-check and save body).

### 2.3 `_logscope_skip_exit_for_tests` request seam in production — 🟠 (reviewer red flag) · S

A `logscope_manage`-gated request param that skips `exit` in the download path — ships in the plugin and produces a malformed response if hit. Gate behind `defined('WP_TESTS_RUNNING')` or drop it. File: `src/REST/LogsController.php:298-334`.

- [x] Done — gated behind `LOGSCOPE_RUNNING_TESTS`, defined only in the PHPUnit bootstrap.

### 2.4 Tail mode ignores mutes — 🟠 correctness · S

`query()` early-returns on the `since != null` branch **above** `resolve_muted_signatures()`, so Live tail re-appends muted signatures — mute looks broken while tailing. File: `src/Log/LogRepository.php:91`.

- [x] Done — mutes resolved before the tail branch and applied to tail results.

### 2.5 `useTailPolling` falsy-zero drops rotation reset — 🟠 correctness · S

`res.last_byte || lastByteRef.current` discards a legitimate `last_byte: 0` after rotation, so the offset never resets and post-rotation entries re-baseline every tick. Use `?? `. File: `assets/src/hooks/useTailPolling.js:94`.

- [x] Done

### 2.6 CSV formula/DDE injection in both exports — 🟠 · S 🔒

`csvCell()` is RFC-4180-correct but doesn't neutralize a leading `= + - @ TAB CR`. Log messages are attacker-influenced; the BOM prepend steers users to Excel. Prefix `'` (or tab) when a cell starts with those chars. Fix once in a shared util (see 4.1). Files: `assets/src/components/LogViewer/index.jsx:1037-1046`, `GroupedView/index.jsx:428-437`.

- [x] Done — new `assets/src/utils/csv.js` (`csvCell` with formula-prefix neutralisation, `timestampForFilename`, `downloadCsv`); both components now import it. Also closes 4.1.

### 2.7 `since` param bypasses the 50 MB read budget — 🟠 auth'd DoS · S 🔒

Tail branch applies no `MAX_BYTES_PER_QUERY` clamp: `GET /logs?since=0` on a multi-GB log `fread`s the whole file and fatals the worker. Fix: `$offset = max($since, $size - MAX_BYTES_PER_QUERY)`. File: `src/Log/LogRepository.php:248-270`.

- [x] Done

### 2.8 `unknown` severity vanishes from Stats tiles/chart — 🟠 correctness · S

`KpiGrid`/`VolumeChart`/`BreakdownBar` hard-code a 6-token `SEVERITY_ORDER`; PHP `Severity::all()` has 7 (incl. `unknown`) and `/stats` totals include it. Result: non-empty summary but "Total 0" tiles and a null chart. Fix by importing the canonical list (see 4.4). Files: `assets/src/components/StatsTab/{KpiGrid,VolumeChart,BreakdownBar}.jsx`.

- [x] Done — all three import `SEVERITY_TOKENS` from `utils/severity.js`; `unknown` stroke added to the chart palette. (Full PHP→JS single-source emit remains 4.4.)

### 2.9 `downloadLogsUrl()` breaks on plain-permalink sites — 🟠 correctness · S

Hand-built URL concatenates onto `restRoot` (= `?rest_route=/` without pretty permalinks), producing two `?` and an unparsed `_wpnonce` → Download returns 404/401. Route through `apiFetch`'s root handling or build the query correctly. File: `assets/src/api/client.js:151`.

- [x] Done — params join with `&` when the REST root already carries `?rest_route=/`.

### 2.10 Keyboard shortcuts dropped when fired from the Settings tab — 🟠 · S

`emitShortcut()` dispatches synchronously right after `ensureLogsTab()`, but the tab switch + LogViewer/FilterBar mount are async, so `g`/`t`/`/` from Settings switch tabs but do nothing else (contradicts the code's own comment). Defer the emit to after mount (e.g. next tick / effect). File: `assets/src/components/App.jsx:110`.

- [x] Done — shortcut parked in state and emitted from an effect after the Logs tab renders.
